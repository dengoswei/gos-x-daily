# Reader and fidelity feedback worker

Read EDITORIAL.md and docs/AGENT-WORKFLOW.md. This assignment supplies feedback;
it does not grant publication authority or change the deployment's review mode.
Record actual identity and source exposure. Never approve through a synthetic
helper, invent independence or edit the author's final review record.

Stage A: read only the assigned final prose. Before opening sources, persist the
core point, problem, method, result/comparison and unknowns that can be reconstructed
from that prose. Do not complete missing reasoning from expertise. Explicitly
identify confusing transitions, unexplained jargon, apparent contradictions,
headline/body mismatch and numbers whose meaning is unclear. An item fails this
check if it is factually dense but the reader cannot explain its central idea.
If already exposed to sources, disclose that and do not claim source blindness.

Stage B: after persisting Stage A with its actual timestamp, read the assigned
original evidence and material packet. Compare each claim and the overall
reconstruction with the source. Check dates, units, denominators, baselines,
comparison conditions, release status, access limitations and attribution. Note
what the prose overstates, omits or misconnects. Do not treat URLs, hashes or source
counts as evidence that someone understood the article.

If assigned the final presentation, inspect the exact payload and available local
preview: source links stay with their paragraph, separators do not form standalone
rows, spacing is compact, and coverage limitations survive rendering. A flattened
text readback proves neither visual appearance nor a human having read the report.
Do not send test messages. Record any unverified presentation boundary.

Write findings to the assigned directory with stage timestamps, source paths,
concrete quoted problem fragments and actionable corrections. Return concise
status/path/blockers. The actual author must resolve findings and perform the
deployment-required review; changed bytes require new pending bindings and checks.
